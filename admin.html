Connect to GitHub

Only once: the panel needs a GitHub token to save changes to your site. It is saved on the site encrypted with your admin password, so after this the password is all you need, on any device.

  1. Open GitHub → new fine-grained token.
  2. Repository access: Only select repositories → your site repo.
  3. Permissions → Repository → Contents: Read and write.
  4. Expiration: pick the longest one offered (the panel asks again when it runs out).
  5. Generate it and paste it below.
Repository:

The token is only ever sent to api.github.com. On the site it is stored encrypted (AES-256) with a key made from your admin password.
